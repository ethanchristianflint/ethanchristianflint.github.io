## Target

- **WCAG 2.2 Level AA** across the whole site.
- Selected **Level AAA** criteria that are realistic to meet: 7:1 text contrast (1.4.6), no time limits (2.2.3), link purpose from the link text alone (2.4.9), section headings (2.4.10) and enhanced focus appearance (2.4.13).

## How it's built

- Plain HTML and CSS generated by Eleventy. No client-side JavaScript, no tracking, no third-party scripts and no fonts loaded from other servers.
- A skip link, landmark regions, one main heading per page and a visible focus outline on everything you can tab to.
- Layout reflows at 320 pixels wide and supports 200% text zoom without loss of content.
- Respects reduced-motion and Windows high-contrast (forced colors) settings.
- Status is always written out in text, never shown by color alone.

## How it's tested

- Automated axe-core checks run on every page each time the site is built and published.
- The first full audit will add manual keyboard-only testing, screen reader testing (NVDA and VoiceOver) and a review using the DHS Trusted Tester process.

## Conformance status

**Not yet fully audited.** The first full audit report will be published here once complete. It will list every issue found, the WCAG criterion it fails, its severity and its fix status.
